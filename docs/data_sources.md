
# Disease data extension to 2025 (Sunaina)

- Raw disease CSVs extended to 2025 (dengue and chikungunya 2021-2025, malaria 2010-2025, from NCVBDC PDFs).
- Dengue values for 2014-2016 were subsequently added to the raw CSV from the cited parliamentary question/source table (36 state entries per year; some source entries are explicitly marked unavailable). The current processed tensor and ST-GNN run include these additions.
- Values for 2021 and 2022 were revised in the new source (identical for 25-94% of pairs depending on disease; median
  log ratio about 0). The current headline model's mean difference from persistence is -0.001 across 2010-2025, and
  +0.011 without 2021; both intervals include 0. The 2021 fold itself favours the model by 0.181 log-MAE.
- A true holdout for the earlier v1 model (trained through 2022, tested on 2023-2025) is not clean because 2022 values were revised. The registered model instead uses rolling-origin evaluation through 2025.
- Zeros: an annual total of exactly 0 is treated as missing when the series has ever reached 100 (300 values in the current tensor). Rerun with
  zeros kept: see the zeros_kept result in the comparison table.
- Andhra Pradesh values before about 2010 are whole numbers times 0.5861509524794264 (cause unconfirmed).
- Whether 2025 is a full year: Yes. NCVBDC labels it as a calendar year (January-December); 2026 is a separate column marked provisional through April.
- Model data cutoff: the current `annual_final` checkpoint was registered on 2026-11-14 UTC, uses the processed disease tensor through 2025, and includes the malaria and chikungunya updates, 2021-2022 revisions, and available dengue 2014-2016 entries.
- Headline weather: synthetic climatology from state profiles, seasonal curves and seeded noise, generated by `src/ingestion/weather/build_weather_tensor.py`; NASA POWER is not used by the registered checkpoint.
